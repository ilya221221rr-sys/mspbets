# Поддержка: сначала ИИ → потом человек + фото

## Как это работает для игрока и для вас

1. Игрок пишет в **Профиль → Поддержка** (или просто пишет боту текст/фото).
2. **Отвечает ИИ-помощник.** Вам в бота при этом **ничего не приходит**.
3. Игрок нажимает **«👤 Позвать человека»** (в приложении или кнопкой под ответом ИИ в боте), либо пишет
   «позовите оператора» / `/human` — **подключаетесь вы**. ИИ сам тоже зовёт вас, если речь о пропавших баллах,
   ошибке расчёта, жалобе или он не знает ответа.
4. Вам в бота приходит: `🆘 Нужен человек — обращение #N` + выписка диалога с ИИ + последнее фото игрока.
5. Отвечаете как раньше: **reply** на сообщение в боте (текстом **или фото**), `/reply N текст`, либо в админке.
   Когда вы ответили — ИИ в этом обращении замолкает. В админке есть кнопка **«🤖 Вернуть ИИ»**.
6. Фото можно прикреплять кнопкой 📎 (в приложении) или просто отправить фото боту. Вы тоже можете отвечать фото.

Если ИИ не настроен или упал — всё работает по-старому: обращение сразу идёт вам.

## Что и куда добавить (5 шагов)

### Шаг 1. Заменить 2 файла (скопировать из папки `mspbets-update/` поверх репозитория)
| Файл из архива | Куда | Что делает |
|---|---|---|
| `extras/support.py` | `extras/support.py` (**заменить**) | ИИ, режимы ai/human, фото, API, бот |
| `web/support.js` | `web/support.js` (**заменить**) | чат с фото, кнопка «Позвать человека», админка |

### Шаг 2. Добавить стили
Откройте `web/support-extra.css`, **скопируйте всё содержимое и вставьте в самый конец `web/extra.css`**.

### Шаг 3. Правки в `app.py` (3 мелкие вставки)
Подробно — в файле `app_py_patch.txt`. Коротко:

1. В импорте `from aiogram.types import ...` добавьте `CallbackQuery`.
2. После хендлера `on_plain_text` (перед `# --- LIFESPAN ---`) вставьте:
```python
@dp.message(Command("human"))
async def cmd_support_human(message: Message): await extras.support.bot_human_cmd(message)

@dp.message(F.photo)
async def on_photo(message: Message): await extras.support.bot_photo(message)

@dp.callback_query(F.data == "sup_human")
async def on_support_human_btn(callback: CallbackQuery): await extras.support.bot_human_cb(callback)
```
3. (Желательно) в `extras/__init__.py` в функции `_init()` добавьте строку `support.init()` после `core.init_schema()`.

`core.py`, `requirements.txt`, `render.yaml` **менять не нужно**: таблица `support_files` и новые колонки
(`support_tickets.mode`, `support_messages.file_id`) создаются автоматически, старые обращения не трогаются
(они остаются в режиме «человек»).

### Шаг 4. Получить ключ ИИ и добавить в Render
Самый простой бесплатный вариант — **Google Gemini** (понимает и текст, и скриншоты):
1. Зайдите на https://aistudio.google.com/apikey → **Create API key**.
2. Render → ваш сервис → **Environment** → добавьте:

| Переменная | Значение | Обязательно |
|---|---|---|
| `AI_API_KEY` | ваш ключ | **да** |
| `AI_MODEL` | `gemini-2.5-flash` (по умолчанию) | нет |
| `AI_BASE_URL` | `https://generativelanguage.googleapis.com/v1beta/openai` (по умолчанию) | нет |
| `AI_VISION` | `1` — отправлять фото ИИ; `0` — не отправлять, если модель не умеет картинки | нет |
| `AI_ENABLED` | `0` — временно выключить ИИ (всё сразу идёт вам) | нет |

Можно взять любого провайдера с OpenAI-совместимым API (Groq, OpenRouter, OpenAI…): поменяйте `AI_BASE_URL`,
`AI_MODEL`, `AI_API_KEY`. Для моделей без зрения поставьте `AI_VISION=0`.

### Шаг 5. Закоммитить и запушить
GitHub Desktop → Commit → Push. Render пересоберёт сервис. В логах появится
`support: ИИ включён, модель gemini-2.5-flash`.

## Как настроить «характер» и знания ИИ
В `extras/support.py` переменная **`SYSTEM_PROMPT`** — это инструкция для ИИ: что он знает о MSPBETS и когда
звать человека. Добавляйте туда новые правила/FAQ обычным текстом (например, «Вывод баллов невозможен»).
Слова, по которым игрок мгновенно зовёт человека, — **`HUMAN_RE`** там же.

## Команды
| Кто | Команда |
|---|---|
| Игрок | любой текст/фото боту · `/human` · кнопка «👤 Позвать человека» |
| Админ | reply на обращение (текст/фото) · `/reply N текст` · `/close N` · `/tickets` (🤖 — отвечает ИИ, 👤 — ждёт вас) |

## Про фото
* Приложение само сжимает фото до ~1280px / ≤1.2 МБ и отправляет на сервер.
* Принимаются только настоящие JPG/PNG/WEBP/GIF (проверка по содержимому), ≤ 1.5 МБ; смотреть фото могут только
  владелец обращения и админы.
* Фото хранятся в Turso (таблица `support_files`) и **автоматически удаляются через 30 дней** (`FILE_TTL_DAYS`).
* В боте отправляйте именно «фото» (не «файл»).

## Что проверено
Серверная логика прогнана на вашем реальном `core.py` (SQLite вместо Turso, заглушка ИИ и бота): режимы ai/human,
отсутствие уведомлений админу в режиме ИИ, кнопка «позвать человека», автоэскалация по маркеру и по ключевым словам,
fallback при сбое ИИ, старые обращения, фото (отправка, права доступа, поддельные файлы, лимит размера), ответ админа
с фото, «Вернуть ИИ», лимит сообщений, фото через бота. **Не проверялось вживую:** реальный запрос к Gemini
(нужен ваш ключ) и отправка в настоящий Telegram — поэтому после деплоя напишите в поддержку тестовое сообщение
и тестовое фото со своего второго аккаунта.
