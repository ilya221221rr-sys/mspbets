Исправление: картинки кейсов и скинов CS2

Причина: app.py отдавал Cache-Control "immutable, max-age=7 дней" даже для ответов 404.
Если картинка хоть раз не нашлась (до деплоя файлов), Telegram/браузер запоминал «пусто» на неделю.

Что изменено:
1) app.py        - ошибки (404 и т.п.) на /web/* больше не кэшируются, "immutable" убран.
2) extras/cases.py - у картинок CS2 в URL добавлено ?v=2 (сбрасывает уже закэшированный 404).
                    Нужно ещё раз сбросить кэш - поменяйте IMG_VER.
3) web/extra.js  - если картинка не загрузилась: повтор без кэша, потом заглушка.
4) tests/*       - тесты учитывают ?v= в URL.

Файлы картинок уже лежат в web/cs2/ (33 скина) и web/cases/cs2_*.webp (2 обложки).
Если вдруг их нет у вас: pip install requests pillow && python tools/fetch_cs2_images.py

Как применить: замените файлы проекта, закоммитьте и запушьте в GitHub -> Render сам пересоберёт сервис.
