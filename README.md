# MSPBETS — Telegram Mini App (виртуальные баллы)

Это стартовый MVP для развлекательных прогнозов на спортивные матчи. Баллы виртуальные: их нельзя купить, пополнить за деньги, вывести, обменять или получить за них денежный приз.

## Что есть
- Telegram-бот с кнопкой открытия Mini App;
- проверка подлинности Telegram WebApp initData;
- профиль игрока и стартовый баланс 1000 виртуальных баллов;
- список матчей и прогноз 1 / X / 2;
- рейтинг игроков;
- админские API для создания и расчёта матчей.

## Запуск локально
1. Установите Python 3.11 или новее.
2. Скопируйте `.env.example` в `.env` и заполните значения.
3. В PowerShell:
   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
4. Задайте переменные окружения из `.env` (для простого локального теста можно использовать PowerShell `$env:NAME="value"`).
5. Запустите:
   ```powershell
   uvicorn app:app --host 127.0.0.1 --port 8000
   ```

## Деплой
`render.yaml` — базовый Blueprint для Render. Нужен публичный HTTPS URL. В настройках сервиса задайте `BOT_WEBAPP_URL` равным адресу сервиса, а `WEBHOOK_SECRET` — длинной случайной строке. `ADMIN_IDS` — числовой Telegram ID администратора.

Важно: бесплатные веб-сервисы могут засыпать, а файловая система бесплатного инстанса может быть временной. SQLite в этом шаблоне подходит для прототипа; перед длительным использованием подключите постоянную базу данных/хранилище. Не обещается круглосуточная работа бесплатного тарифа.

## Безопасность
- Не публикуйте `BOT_TOKEN`, `WEBHOOK_SECRET` и `.env`.
- Не включайте `ALLOW_DEV_AUTH=true` на публичном сервере.
- Не выдавайте баллам денежную стоимость и не делайте их обменными.
