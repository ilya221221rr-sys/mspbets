# MSPBETS — букмекер на виртуальные баллы (Telegram Mini App)

Next.js (App Router) + PostgreSQL (Drizzle). Баллы виртуальные: их нельзя купить, вывести или обменять.

## Что внутри
- **Линия**: Dota 2, CS2, футбол. Рынки: исход, тотал, фора, обе забьют, первая кровь, 1-я карта. Коэффициенты считаются из вероятностей с маржой 6%.
- **Live**: ставки закрываются по времени старта, админ меняет счёт — коэффициенты пересчитываются.
- **Купон**: ординар (каждое событие отдельно) и экспресс, защита от смены коэффициента, кешаут для ординаров.
- **Автоматический расчёт** по счёту, возвраты при отмене, уведомления в Telegram о результате ставки.
- **Игры**: краш (общие раунды, provably fair), мины, дайс, кейсы (RTP ≈ 94%, шансы открыты), апгрейд (шанс на экране = реальный).
- **Удержание**: ежедневный бонус с серией, уровни/XP, промокоды, рефералка, рейтинг (прибыль за неделю / баланс).
- **Единый журнал баллов (`ledger`)**: баланс меняется только атомарно, каждая операция записана.
- **Админка** (`/admin`): дашборд, создание матчей и автогенерация линии, коэффициенты, приостановка рынков, расчёт, игроки (с обязательной причиной для начислений), промокоды, рассылка, лог действий.

## Переменные окружения
| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | PostgreSQL |
| `BOT_TOKEN` | токен бота — включает вход через Telegram и уведомления |
| `BOT_USERNAME` | имя бота (для реферальных ссылок) |
| `WEBAPP_URL` | публичный HTTPS-адрес приложения |
| `WEBHOOK_SECRET` | секрет вебхука бота (затем в админке «Установить webhook бота») |
| `ADMIN_IDS` | Telegram ID админов через запятую |
| `ADMIN_KEY` | ключ разблокировки админки (запасной вариант) |
| `SESSION_SECRET` | секрет подписи сессий |
| `DISABLE_GUEST=true` | запретить гостевой вход (для продакшена в Telegram) |

Если не заданы ни `ADMIN_IDS`, ни `ADMIN_KEY`, первым админом становится самый первый зарегистрированный игрок.

## Запуск
```
npm install
npx drizzle-kit push
npm run build && npm start
```
